# 🚀 دليل رفع وتشغيل مشروع BUA على خادم Hostinger VPS

هذا الدليل يشرح لك خطوة بخطوة كيفية رفع المشروع على سيرفرك (VPS) وتشغيله بنقرة زر واحدة عبر السكريبت الآلي المجهز لك.

---

## 📋 المتطلبات قبل البدء:
1. سيرفر VPS من Hostinger (نظام تشغيل **Ubuntu 22.04 LTS** أو **Ubuntu 24.04 LTS**).
2. عنوان الـ IP الخاص بالسيرفر وكلمة مرور الـ `root`.

---

## 🛠️ الخطوة 1: نسخ ملفات المشروع إلى السيرفر

يمكنك رفع مجلد المشروع إلى السيرفر بأحد الطريقتين:

### الطريقة (أ): عبر برنامج FileZilla (الأسهل بواجهة مرئية):
1. افتح برنامج **FileZilla**.
2. اكتب في خانة الـ Host: `sftp://YOUR_SERVER_IP`
3. اسم المستخدم: `root` وكلمة المرور الخاصة بسيرفرك، ثم اضغط **Quickconnect**.
4. انتقل في جهة السيرفر إلى المسار: `/var/www/`
5. ارفع مجلد المشروع وسمّه `bua` (بحيث يكون المسار الكامل: `/var/www/bua`).

### الطريقة (ب): عبر سطر الأوامر (SCP):
من جهازك داخل مجلد المشروع، اكتب:
```bash
scp -r "d:\BUA\id site\dev\student_v2" root@YOUR_SERVER_IP:/var/www/bua
```

---

## ⚡ الخطوة 2: تشغيل سكريبت الإعداد الشامل بنقرة واحدة (Docker Master Setup)

1. اتصل بسيرفرك عبر الـ Terminal / PowerShell:
   ```bash
   ssh root@YOUR_SERVER_IP
   ```

2. ادخل إلى مجلد المشروع وشغّل سكريبت الإعداد الشامل:
   ```bash
   cd /var/www/bua
   bash deploy/vps_master_setup.sh
   ```

### 🤖 ماذا سيفعل السكريبت تلقائياً بالكامل؟
- ✅ **تثبيت Docker & Docker Compose**: تثبيت محرك الدوكر الرسمي وأحدث إصدار تلقائياً.
- ✅ **تشغيل PostgreSQL داخل Docker**: حاوية معزولة ومحمية `bua_postgres` مع فحص صحة `pg_isready` وتخزين دائم على قرص الـ NVMe.
- ✅ **حماية أمنية مشددة (Firewall & Anti-Brute-Force)**:
  - تفعيل جدار حماية **UFW** (السماح فقط للمنافذ 22 SSH, 80 HTTP, 443 HTTPS).
  - حظر المنفذ 5432 خارجياً تماماً (قاعدة البيانات معزولة داخل شبكة Docker الداخلية).
  - تفعيل **Fail2ban** لحظر أي محاولات هجوم أو تخمين كلمات مرور.
- ✅ **خادم Nginx العكسي**: استقبال الزوار على المنفذ 80/443 وتمرير الطلبات بسرعة وتطبيق ترويسات الأمان (OWASP Security Headers).
- ✅ **تهيئة الجداول والمستخدمين**: فحص وتشغيل `init_db()` لإنشاء الجداول وحساب المشرف العام تلقائياً.
- ✅ **جدولة النسخ الاحتياطي التلقائي إلى Google Drive**:
  - إنشاء مهمة Cronjob يومية الساعة 3:00 فجراً لرفع نسخة احتياطية مضغوطة من قاعدة البيانات والصور إلى Google Drive.

---

## 🌐 الخطوة 3: تفعيل الدومين وشهادة الأمان المجانية (SSL / HTTPS)

إذا كان لديك دومين (مثال: `portal.bua.edu.eg` أو `yourdomain.com`):

1. ادخل إلى لوحة تحكم الدومين وأضف سجل **A Record** يشير إلى عنوان IP السيرفر:
   - **Type:** `A`
   - **Name:** `@` (أو `portal`)
   - **Value:** `YOUR_SERVER_IP`

2. بعد دقائق، افتح الـ Terminal الخاص بالسيرفر واكتب الأمر التالي:
   ```bash
   sudo certbot --nginx -d yourdomain.com
   ```
3. سيسألك عن بريدك الإلكتروني والموافقة على الشروط، وسيقوم تلقائياً بتفعيل شهادة التشفير الخضراء **HTTPS** وتجديدها تلقائياً مجاناً للأبد!

## 🔧 أوامر إدارة السيرفر السريعة (Cheatsheet):

* **معرفة حالة تشغيل الموقع:**
  ```bash
  systemctl status bua
  ```
* **إعادة تشغيل الموقع (بعد أي تعديل في الكود):**
  ```bash
  systemctl restart bua
  ```
* **مشاهدة سجلات الأخطاء والزيارات مباشرة:**
  ```bash
  journalctl -u bua -f
  ```
* **أخذ نسخة احتياطية يدوية فورية:**
  ```bash
  bash /var/www/bua/deploy/backup.sh
  ```
